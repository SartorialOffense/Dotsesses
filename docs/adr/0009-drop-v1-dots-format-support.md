# `.dots` v1 format support is dropped

`SavedState.Version = 2` is the minimum supported `.dots` format.
Older v1 files no longer load. Any v1 example fixtures and the
v1-round-trip tests are removed during the GradingSession rework.

## Why

v1 was a stub format that predates persisted ScoreSelections (see
ADR-0001). Maintaining the silent v1→v2 migration path costs
explicit test surface and code complexity for a single-user product
whose user has explicitly opted out of needing it. ADR-0002's
forward-compat pattern (default-cleanly migration via `= new()`
initializers and silent re-save on first save-after-load) remains in
place for future v2→v3 transitions and beyond.

## Consequences

- Any existing v1 `.dots` file must be regenerated by re-loading its
  Excel source and re-saving. There is no in-product migration path.
- The `Version` field on `SavedState` is now a *minimum* gate, not a
  migration entry point. The loader rejects `Version < 2`.
- This is a one-time scope reduction; the broader versioning
  discipline from ADR-0002 still applies going forward.
